# Render Deployment

This backend is ready for Render as a Node web service.

## Blueprint Deploy

Use the root-level `render.yaml` from this repository. Render will deploy:

- Root directory: `backend`
- Build command: `npm ci`
- Start command: `npm start`
- Health check: `/`

Set `MONGO_URI` in the Render dashboard when prompted. `JWT_SECRET` is generated by the Blueprint.

## Manual Deploy

If you create the service manually:

1. Create a new Render Web Service from this GitHub repo.
2. Set Root Directory to `backend`.
3. Set Build Command to `npm ci`.
4. Set Start Command to `npm start`.
5. Add environment variables:
   - `MONGO_URI`
   - `JWT_SECRET`
   - `NODE_ENV=production`

Do not upload `backend/.env` to GitHub. Use `backend/.env.example` as the template only.

After Render gives you a backend URL, run the Flutter app with:

```powershell
flutter run --dart-define=API_BASE_URL=https://your-render-service.onrender.com/api
```
